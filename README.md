# Dev Armory

A reusable collection of software engineering workflows for coding agents.

The project captures general engineering practices that can be applied across different repositories, technology stacks, and agent implementations.

The goal is to provide a consistent way of approaching development work while still respecting the architecture, tooling, and conventions of each individual project.

## Principles

* Repository conventions come first.
* Guidance should be technology-agnostic where possible.
* Reusable workflows should encode engineering practice, not project-specific details.
* Specialized guidance should be added only when it is useful across multiple projects.
* The project should remain independent of any specific coding agent whenever possible.

Project-specific rules belong in the repository itself, while this project provides the reusable engineering layer.
